# Decision Trees

Los **árboles de decisión** son un *algoritmo de aprendizaje supervisado* muy utilizado para tareas de clasificación y regresión. Destacan por su estructura intuitiva en forma de árbol, lo que los hace fácil de entender o interpretar. En esencia, *un árbol de decisión crea un modelo que predice el valor de una variable objetivo mediante el aprendizaje de reglas de decisión sencillas deducidas a partir de las características de los datos*.

# Building a Decision Tree

Construir un arbol de decisiones implica seleccionar la mejor característica para dividir los datos en cada nodo. Esta selección se basa en medidas como la **Gini Impurity**, **Entropy** o **Information Gain**, que cuantifican la homogeneidad de los subconjuntos resultantes de la división. El objetivo es crear divisiones que den lugar a subconjuntos cada vez más puros, en los que los puntos de datos de cada subconjunto pertenezcan predominantemente a la misma clase.

###### Gini Impurity

La **Impureza de Gini** mide la probabilidad de clasificar erróneamente un elemento elegido al azar de un conjunto. Una impureza de Gini más baja indica que el conjunto es más puro. La formula es:

$$
Gini(S) ) 1 - Σ (pi)^2
$$

Donde:

- `s` es el conjunto de datos.
- `pi`es la proporción de elementos que pertenecen a la clase `i` en el conjunto.

Consideremos un conjunto de datos `s` con dos clases: `A` y `B`. Supongamos que en el conjunto de datos hay 30 instanacias de clases `A` y 20 instanacias de la clase `B`.

- Proporción de la clase `A`: $pA = 30 / (30 + 20) = 0.6$
- Proporción de la clase `B`: $pB = 20 / (30 + 20) = 0.4$

La impureza de GVini para este conjunto de datos es:

$$
Gini(S) = 1 - (0.6^2 + 0.4^2) = 1 - (0.36 + 0.16) = 1 - 0.52 = 0.48
$$

###### Entropy

La **Entropy** (*Entropía*) mide el desorden o la incertidumbre de un conjunto. Una entropía más baja indica que el conjunto es más homogéneo. La fórmula de la entropía es:

$$
Entropy(S) = - Σ  pi * log2(pi)
$$

Donde:

- `S` es el dataset.
- `pi` es la proporción de elementos que pertencen a una clase `i` en el set.

Usando el mismo conjunto de datos `S` con 30 instancias de una clase `A` y 20 instancias de una clase `B` :

- Proporción de la clase `A`: `pA = 0.6`.
- Proporción de la clase `B`: `pB = 0.4`.

La entroía para el conjunto de datos sería:

```python
Entropy(S) = - (0.6 * log2(0.6) + 0.4 * log2(0.4))            
           = - (0.6 * (-0.73697) + 0.4 * (-1.32193))            
           = - (-0.442182 - 0.528772)            
           = 0.970954`
```

###### Information Gain

La **Information Gain** (*Ganancia de información*) mide la reducción de la entropía que se consigue al dividir un conjunto en función de una característica concreta. Para la división se elige la característica con mayor ganancia de información. La fórumula de la ganancia de información es:

$$
Information Gain(S, A) = Entropy(S) - Σ ((|Sv| / |S|) * Entropy(Sv))
$$

Donde:

- `S` es el conjunto de datos.
- `A` es la característica utilizada para la división.
- `Sv`es el subconjunto de `S`para cada caracteristica `A` toma el valor `V`.

Consideremos un conjunto de datos `S` con 50 instancias yu dos clases: `A` y `B`. Supongamos que se considera una característica `F` que puede adoptar dos valores: `1` y `2`. La distribución del conjunto de datos es la siguiente:

- Para  `F = 1`: 30 instancias, 20 clases `A`, 10 clases `B`.
- Para `F = 2`: 20 instancias, 10 clases `A`, 10 clases `B`.

Primero, se calcula la *entropía* del conjunto de datos `S` entero:

```python
Entropy(S) = - (30/50 * log2(30/50) + 20/50 * log2(20/50)) 
		   = - (0.6 * log2(0.6) + 0.4 * log2(0.4)) 
		   = - (0.6 * (-0.73697) + 0.4 * (-1.32193)) 
		   = 0.970954
```

Despues, se calcula la antroía de cada subconjunto `Sv`:

- Para `F = 1`:
	- Proporción de la clase `A`: `pA = 20/30 = 0.6667`.
	- Proporción de la clase `B`: `pB = 10/30 = 0.3333`.
	- Entropy(S1) = `- (0.6667 * log2(0.6667) + 0.3333 * log2(0.3333)) = 0.9183`.

- Para `F = 2`: 
	- Proporción de la clase `A`: `pA = 10/20 = 0.5`.
	- Proporción de la clase `B`: `pB = 10/20 = 0.5`.
	- Entropy(S2) = `- (0.5 * log2(0.5) + 0.5 * log2(0.5)) = 1.0`.

Luego, calculamos la entroía media ponderada de los subconjuntos:

```python
Weighted Entropy = (|S1| / |S|) * Entropy(S1) + (|S2| / |S|) * Entropy(S2) 
                 = (30/50) * 0.9183 + (20/50) * 1.0 
                 = 0.55098 + 0.4 
                 = 0.95098
```

Finalmente, calculamos la *Information gain*:

```python
Information Gain(S, F) = Entropy(S) - Weighted Entropy
                       = 0.970954 - 0.95098
                       = 0.019974
```

# Building the Tree 

El **Tree** (*Árbol*) comienza con el nodo raíz y selecciona la característica que mejor divide los datos según uno de estos criterios (*Impureza de Gini*, *Antropia* o *Ganancia de Información*). Esta característica se conveirte en el nodo interno y se crea ramas para cada valor posible o rango de valores de dicha caracteristica. A continuacion, los datos se dividen en subconjuntos en funcion de estas ramas. Este proceso conitnua de ofmra recursiva para cada subconjunto hasta que se cumple un criterio de parada.

El arbol deja de crecer cuando se cumple una de las siguientes condiciones:

- **Maximum Deeph**: El arbol alcanza una profundidad maxima especificada, lo que evita que se vuelva excesivamente complejo y que, potencialmente, se produzca un sobreajuste de los datos.
- **Minimum Number of Data Points**: El numero de puntos de datos en un nodo cae por deabjo de un umbral especificado, lo que garantiza que las divisiones sean significativas y no se basen en subconjuntos muy pequeños.
- **Pure Nodes**: TOdos los puntos de datos de un nodo pertenecen a la misma clase, lo que indica que nuevas divisiones no mejorarian la pureza de los subconjuntos.

# Data Assumtions

Una de las ventajas de los árbols de decisión es que parten de un número mínimo de supuestos sobre los datos:

- **No Linearity Assumtion**: Los árboles de decisión pueden manejar relaciones lineales y no lineales entre las características y la variable objetivo. Esto los hace más flexibles que algoritmos como la regresión lineal, que asumen una relación lineal.
- **No Normality Assumtion**: No es necesario que los datos signa una ditribución normal. Esto contrasta con algunos métodos estadísticos que requieren la normalidad para obtener inferencias válidas.
- **Handles Outliers**: Los árboles de decisión son relativamente robustos frente a los valores atípicos. Dado que dividen los datos en función de los valores de características, en lugar de basarse en cálculos de distancia, es menos probable que los valores atípicos tengan un impacto significativo en la estructura del árbol.

Estas hipótesis mínimas contribuyen a la versatilidad de los árboles de decisión, lo que permite aplicarlos a una amplia gama de conjuntos de datos y problemas sin necesidad de un preprocesamiento o transformaciones exhaustivas.
