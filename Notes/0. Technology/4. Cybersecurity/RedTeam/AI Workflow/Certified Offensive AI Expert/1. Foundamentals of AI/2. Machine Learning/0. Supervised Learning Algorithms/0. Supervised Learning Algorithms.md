# Supervised Learning Algorithms

Los algoritmos de *aprendizaje supervisado* (**Supervised Learning**) constituyen la piedra angular de muchas aplicaciones de aprendizaje automático (ML), ya que permiten a los sitemas aprender a partir de datos etiquetados y realizar predicciones precisas. En el aprendizaje supervisado, cada punto de datos está asociado a un resultado o etiqueta conocida. Por ejemplo como si tuvieramos un conjunto de ejemplos con las respuestas correctas ya proporcionadas.

El objetivo del algoritmo es aprender una función de correspondencia que permita predecir la etiqueta de datos nuevos y desconocidos. Este proceso implica identificar patrones y relaciones entre las características (Variables de entrada) y las etiquetas corresopndientes (Variables de salida), lo que permite al algoritmo generalizar su conocimiento a nuevas instancias.

----
# How it works?

Los alrgoritmos de aprendizaje supervisado r*eciben un conjunto de datos con ejemplos etiquetados y utilizan estos datos para entrenar un modelo capaz de predecir las etiquetas de ejemplos nuevos entrantes y desconocidos*. El proceso de entrenamiento consiste en ajustar los parámetros del modelo para minimizar la diferencia entre sus predicciones y las etiquetas reales.

Los **principales problemas** del aprendizaje supervisado pueden clasificarse a grandes rasgos en dos tipos principales:

1. **Classification**: En los problemas de clasificación, el objetivo es predecir una etiqueta categórica. (Ej. Clasificar correos electrónicos como spam o no spam).
2. **Regression**: En los probelmas de regresión, el objetivo es predecir un valor continuo. (Ej. Predecir el precio de una vivienda en función de su tamaño, ubicación y otras características).

# Core Concepts

Comprender los conceptos fundamentales del aprendizaje supervisado es esencial para entenderlo de forma eficaz. Estos conceptos constituyen los pilares básicos para comprender cómo los algoritmos aprenden a partir de datos etiquetados para realizar predicciones precisas.
###### Training Data
Los *datos de entrenamiento* (**Training Data**) son la base del aprendizaje supervisado. Es el *dataset* (Conjunto de datos) etiquetados que se utiliza para entrenar el modelo de aprendizaje automático. Este conjunto de datos está formado por características de entrada y sus correspondientes etiqeutas de salida. *La calidad y la cantidad de los datos de entrenamiento influyen de manera significativa* en la **presición del modelo** y en su capacidad para generalizar a dots nuevos y desconocidos.
###### Features
Las *características* (**Features**) son las *propiedades o rasgos medibles* de los datos que sirven como entrada para el modelo. Son las variables que utiliza el algoritmo para aprender y realizar predicciones. La selección de características relevantes es fundamental para crear un modelo eficvaz.

Por ejemplo, cuando predecimos precios de casas, las caracaterísticas podrían incluir:
- Tamaño.
- Número de habitaciones.
- Localización
- Antigüedad. 

###### Labels
Las *etiquetas* (**Labels**) son los *resultados conocidos* o las variables objetivo asociadas a cada punto de datos del conjunto de entrenamiento. Representan las *respuestas correctas* que el modelo pretende predecir.

Continuando con el ejemplo de la casa, el label correspondería al precio asociado a cada casa con sus respectivas características.

###### Model
El *modelo* (**Model**) es una representación matemática de la *relación entre las características y las etiquetas*. Es aprendido a raíz de los datos de entrenamiento y se utiliza para predecir nuevos datos entrantes. El modelo puede considerarse una función que toma las características como entrada y genera una predicción de la etiqueta como salida.

###### Training
El *entrenamiento* (**Traning**) es el proceso que consiste en introducir los datos de entrenamiento al algoritmo y ajustar los parámetros del modelo para minimizar los errores de predicción. El algoritmo aprende a partir de los datos de entrenamiento ajustando de forma iterativa sus parámetros internos para mejorar la precisión de sus predicciones.

###### Prediction
Una vez entrenado el modelo, se puede utilizar para realizar nuevas *predicciones* (**Predictions**) de datos nuevos y desconocidos. Para ello, hay que proporcionar al modelo las características del nuevo punto de datos, y el modelo generará una predicción sobre la etiqueta. La predicción es una aplicación específica de la inferencia, centrada en generar resultados útiles, como clasificar un correo electrónico como spam o pronosticar la cotización de las acciones.

###### Inference 
La *inferencia* (**Inference**) es un concepto más amplio que abarca la predicción, per que también incluye la comprensión de la estructura y los patrones subyacentes en los datos. Implica utilizar un modelo entrenado para obtener información, estimar parámetros y comprender las relaciones entre variables.

Por ejemplo, la inferencia puede consistir en determinar qué características son las más importantes en un *árbol de decisiones*, estimar los coeficientes en un modelo de regresión lineal o analizar cómo las diferentes entradas influyen en las predicciones del modelo.

###### Evaluation
La *evaluación* (**Evaluation**) es un paso fundamental en el aprendizaje supervisado. Consiste en evaluar el rendimiento del modelo para determinar su precisión y su capacidad de generalización a nuevos datos. Entre las métricas de evaluación más comunes se incluyen:

- *Accuracy*: La proporción de predicciones correctas realizadas por el modelo.
- *Precision*: La proporcion de predicciones verdaderas positivas entre todas las predicciones positivas.
- *Recall*: La proporción de predicciones posivas verdaderas entre todas las instancias positivas reales.
- *F1-score*: Una medida armónica de la precisión y la recuperación, que proporciona una medida equilibrada del rendimiento del modelo.

###### Generalization
La *generalización* (**Generalization**) es la cpacaidad del modelo para predecir con precisión los resultados de datos nuevos y desconocidos que no se han utilizado durante el entrenamiento. Un modelo que generaliza bien puede aplicar de forma eficas los conocimientos adquiridos a situaciones del mundo real.

> [!warning] ###### Overfitting
> El *sobreajust* (**Overfitting**) ocurre cuando un modelo aprende demsiado bien los datos de entrenamiento, *incluyendo el ruido y los valores atípicos*. Esto puede dar lugar a una mala generalización a nuevos datos, ya que el modelo ha memorizado el conjunto de entrenamiento en lugar de aprender los patrones subyacentes.

> [!warning] ###### Underfitting
> El **Underfitting**se produce cuando un modelo es demasiado simple para captar los patrones subyacentes de los datos. Esto da lugar a un rendimiento deficientae tanto en los datos de entrenamiento como en los datos nuevos y desconocidos.

###### Cross-Validation
La *validación cruzada* (**Cross-Validation**) es una técnica utilziada para evaluar en qué medida un modelo se generalizará a un conjunto de datos independientes. Consiste en dividir los datos en varios subconjuntos (folds - plieges) y entrenar el model ocon diferentes combinaciones de estos folds, mientras que se valida con el fold restante. Esto ayuda a reducir el *overfitting* y proporciona una estimación más fiable del rendimiento del modelo.

###### Regularization
La *regularización* (**Regularization**) es una técnica que se utiliza para evitar el *overfitting* mediante la incorporación de un término de penalización a la función de pérdida. Esta penalización disuade al modelo de aprender patrones excesivamente complejos que podría no generalizarse bien. Entre las técnicas de regularización se inlcuyen:

- *L1 Regularization*: Añade penalizaciones equivalentes al valor absolutode la magnitud de los coeficientes.
- *L2 Regularizaton*: Añade una penalización igual al cuadrado de la magnitud de los coeficientes.
